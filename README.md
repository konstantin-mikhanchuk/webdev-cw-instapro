# Instapro

MVP социальной сети для обмена фотографиями

Реализованная функциональность

• Динамическая лента публикаций: Интегрировали верстку списка постов с API, настроили отображение реальных фотографий, имен авторов и текстов постов.
• Добавление новых постов: Реализовали полноценную страницу добавления публикации с полем ввода описания и загрузкой изображения в облако.
• Страница пользователя: Настроили просмотр ленты постов конкретного юзера с переходом по клику на его имя или аватарку.
• Функционал лайков: Реализовали мгновенную постановку и снятие лайков без перезагрузки всей страницы с динамическим пересчетом счетчика.

### Список дополнительных фич

• Защита от XSS-атак (Безопасность): Внедрена функция экранирования HTML-тегов (safeHtml) — любые теги, введенные пользователями в формах или описании, отображаются как безопасный текст и не могут навредить приложению.
• Интерфейсные особенности (Мгновенный рендеринг): Лайки и добавление постов обновляют интерфейс на лету за счет точечной перерисовки компонентов, избавляя пользователя от необходимости перезагружать вкладку.
• Оптимизация архитектуры кода: Использованы встроенные методы и утилиты проекта (хелперы для localStorage и единый переиспользуемый компонент для общей и персональной ленты постов), что уменьшило дублирование кода.
